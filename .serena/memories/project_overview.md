# Project Overview: Старый Кронштадт Website

## Purpose
Информационный сайт о городе Кронштадт, представляющий его историю, достопримечательности, галерею фотографий и современное состояние города.

## Tech Stack
- HTML5
- Bootstrap 5.3.0 (CSS framework)
- Animate.css 3.7.2 (animations)
- FontAwesome 6.4.0 (icons)
- WOW.js (scroll animations)
- jQuery
- Custom CSS
- Custom JavaScript

## Code Structure
```
/
├── index.html          # Главная страница
├── css/
│   └── style.css      # Основные стили
├── js/
│   └── main.js        # JavaScript логика
├── images/           # Изображения
└── favicon.ico        # Фавикон
```

## Key Sections
1. Hero section - Главная секция с фоном
2. History - История Кронштадта
3. Attractions - Достопримечательности
4. Gallery - Галерея фотографий
5. Modern - Современный Кронштадт
6. Contacts - Контактная информация и карта

## Features
- Фиксированная навигация с адаптивным меню
- Scroll-based навигация
- Анимации при скролле (WOW.js)
- Галереи с модальными окнами
- Адаптивный дизайн
- Карта Яндекс (в секции контактов)
