# Task Completion Checklist - Старый Кронштадт Website

## После завершения задачи:

1. **Тестирование в браузере**
   - Открыть index.html
   - Проверить все секции
   - Проверить навигацию
   - Проверить галереи
   - Проверить адаптивность (mobile view)

2. **Проверка консоли**
   - F12 → Console
   - Убедиться, что нет ошибок JavaScript

3. **Cross-browser тестирование**
   - Проверить в Chrome, Safari, Firefox
   - Проверить на мобильных устройствах

4. **Git commit**
   - `git status`
   - `git add .`
   - `git commit -m "описание изменений"`

5. **Дополнительные проверки (если применимо)**
   - Проверить производительность (Lighthouse)
   - Проверить доступность
   - Проверить SEO мета-теги

## Специфично для этого проекта:
- Проверить, что все галереи открываются в модальном окне
- Проверить, что WOW.js анимации работают при скролле
- Проверить, что навигация подсвечивает активную секцию
- Проверить, что карта загружается корректно
